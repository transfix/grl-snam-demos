# GRL-SNAM — demo deliverables

Project page and self-contained demo pages for the GRL-SNAM navigation work
(July – August 2026): the one-command pipeline + live-metrics HUD, fog-of-war
belief navigation, and eight-vehicle squads at city scale.

**Site:** https://transfix.github.io/grl-snam-demos/

- [`2026-07-grl-snam-cli-demo/`](2026-07-grl-snam-cli-demo/) — CLI + live-metrics demo
- [`2026-08-fog-of-war-nav/`](2026-08-fog-of-war-nav/) — fog of war: the map is a belief
- [`2026-08-fog-of-war-at-city-scale/`](2026-08-fog-of-war-at-city-scale/) — squads, convoy, pursuit, rendezvous

Each directory is a self-contained deliverable page (`index.html` + films).
Every number on the pages replays from a recorded trace — nothing is
re-simulated for display.

Core repo: https://github.com/CVC-Lab/GRL-SNAM
